# Купинский район — Новости

Мобильный новостной сайт о Купино и населённых пунктах Купинского района Новосибирской области.

## Публикация сайта
1. Откройте **Settings → Pages**.
2. В поле **Build and deployment → Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** и проверьте запуск **Deploy site to GitHub Pages**.

## Почасовая лента новостей
Workflow `.github/workflows/hourly-news.yml` запускается каждый час на 17-й минуте и по ручному запуску. Скрипт читает RSS/Atom из `sources.json`, фильтрует публикации и обновляет `data/news.json`. Главная страница автоматически показывает эту ленту.

**Важно:** все источники в `sources.json` пока выключены. Перед включением проверьте точный RSS-адрес и условия использования каждого источника. Сайт показывает только заголовок, короткий анонс, название источника и ссылку на оригинал; полные статьи и чужие фотографии не копируются.

## Настройки Actions
Для почасового workflow разрешите запись в репозиторий: **Settings → Actions → General → Workflow permissions → Read and write permissions**.

Погода и реальная форма отправки новостей пока не подключены. Не публикуйте контактные данные редакции, пока не настроите отдельный адрес.
